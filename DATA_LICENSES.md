# Data licenses and provenance

**This file is about DATA, not code.** The code is MIT (see [LICENSE](LICENSE)).
No third-party dataset is redistributed in this repository: every raw or derived
data file lives under `data/` and is gitignored.

Rule of thumb used here: if the license could not be verified on the source page
on the date shown, the dataset is marked **UNVERIFIED** and must not be
redistributed or used in anything public until that is fixed.

| dataset | what we use it for | source | license (as observed) | status |
|---|---|---|---|---|
| **IMC25 Smishing Dataset** (`reportsmishing/Smishing-Dataset-IMC25`) | real scam test rows (`source=external_reported`, stratum `external_scam`); a cluster-capped slice is also used for training | HuggingFace dataset card | **CC BY 4.0** | OK with attribution. > Contains information from the IMC25 Smishing Dataset and the UCI SMS Spam
> Collection, both used under CC BY 4.0. ScamLens reports derived metrics only;
> the underlying messages are not redistributed.

## What is safe to commit

| path | commit? | why |
|---|---|---|
| `docs/`, `src/`, `configs/`, `tests/`, `notebooks/`, `results/*.md` | yes | code, docs and aggregate metrics |
| `results/phase4.json`, `results/metrics.json` | yes | aggregate metrics only — no message text |
| `data/**` | **no** (gitignored) | raw/derived messages, may contain personal data |
| `models/**`, `outputs/**`, `checkpoints/**`, `*.pt`, `*.parquet` | **no** (gitignored) | weights and data files |
| `.env` | **no** (gitignored) | API keys |

Run `python scripts/scan_repo.py` before any push: it fails if a phone number,
UPI id, email address or API key pattern appears in a committable file.
